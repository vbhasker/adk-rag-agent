RAG Weekend

From BM25 to Agentic RAG with Google ADK

Eight standalone chapters, each a runnable project with a lesson and a live playground. Friday night you learn how search ranks words; Sunday afternoon you ship a fact-checked multi-agent RAG system.

🗓 One weekend🐍 Python + ADK🧪 Live playgrounds🚲 Nimbus Bikes corpus

How to use this course

  1. Click a chapter below to read its lesson (works straight from disk).
  2. For the playground, run it: cd chapter-0X-… && python server.py, then open http://localhost:800X.
  3. Do the "Try this" list, skim "Walk the code", and pick one exercise from the chapter README.

Setup, Gemini keys and troubleshooting are in README.md.
