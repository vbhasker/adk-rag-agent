# Display Error Codes Reference

When the controller detects a problem, the display shows an error code. Most codes clear after a restart. If a code returns, follow the action below or contact support with the code and your bike's serial number.

## Error code table

- **E-01 – Low voltage.** The battery is almost empty. Charge the battery fully.
- **E-03 – Brake sensor fault.** A brake lever sensor is stuck. Squeeze both brake levers firmly and release them. Check the sensor cable connectors.
- **E-04 – Throttle fault.** The throttle is not in the zero position at start-up. Release the throttle and restart the bike.
- **E-07 – Motor overheating.** The motor temperature is above 120 °C, usually after a long climb with a heavy load in Turbo mode. Stop riding and let the motor cool for 15 to 20 minutes. Use a lower assist level on long climbs.
- **E-09 – Speed sensor fault.** The spoke magnet is misaligned or missing. Align the magnet within 3 mm of the sensor on the chainstay.
- **E-10 – Controller communication error.** The display cannot talk to the controller. Check that the display cable is fully plugged in and not pinched.
- **E-12 – Battery management system (BMS) fault.** The BMS detected an internal battery issue such as cell imbalance. Stop using the battery and contact support. Do not attempt to open the battery.

## Resetting the display

Hold the power button and the minus button together for 5 seconds to clear stored codes after the issue is fixed.
